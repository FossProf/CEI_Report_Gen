# Release Guide

This guide documents the preferred local release path for the current SPINgen baseline.

## Authoritative Release Command

```powershell
.\scripts\build-release.ps1
```

This is the preferred command for producing a current installer and release package.

## What the Script Does

The release script:

- cleans prior artifact folders
- restores NuGet packages
- builds the solution
- runs the current automated verification path unless skipped
- publishes the app for `win-x64`
- verifies the published executable version
- builds the MSI from verified publish output
- creates a portable ZIP
- writes release manifests and hashes

## Expected Outputs

- `artifacts\\publish\\win-x64\\`
- `artifacts\\installer\\SPINgen_0.3.1-alpha_x64.msi`
- `artifacts\\release\\SPINgen_0.3.1-alpha_win-x64.zip`

## Common Variants

```powershell
.\scripts\build-release.ps1 -SkipInstaller
.\scripts\build-release.ps1 -SkipTests
.\scripts\build-release.ps1 -KeepArtifacts
```

## Release Verification

Recommended verification after building:

1. install the MSI
2. launch SPINgen
3. open or create a project
4. create a report
5. generate a DOCX
6. uninstall
7. confirm user project data remains

## Important Rule

Do not package directly from stale publish output. Build the installer from the verified output generated by the current release script.
