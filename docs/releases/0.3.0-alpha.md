# SPINgen 0.3.0-alpha

- Release tag: `v0.3.0-alpha`
- Release commit SHA: the tagged `v0.3.0-alpha` release commit
- Build configuration: `Release`
- Target runtime: `win-x64`
- Installer filename: `SPINgen_0.3.0-alpha_x64.msi`
- Publish directory: `artifacts/publish/win-x64/`
- Supported OS: Windows 10/11 x64
- Release date: August 9, 2026

## Feature Summary

- project/report lifecycle from creation through finalization
- CEI/Cornerstone branding and SPINgen application identity
- project dashboard with compact readiness indication
- Reports and Search workspaces sharing one report grid
- keyword search with status, weather, and inclusive date filters
- search-result context snippets, tooltips, and keyboard navigation
- safe report deletion with atomic staging and cleanup

## Automated Test Summary

- `dotnet clean CEI_Report_Gen.sln --configuration Release`
- `dotnet restore CEI_Report_Gen.sln`
- `dotnet build CEI_Report_Gen.sln --configuration Release`
- smoke/regression suite
- self-contained publish
- MSI build
- all completed successfully on August 9, 2026

## Manual Test Summary

- manual desktop acceptance remains environment-dependent
- interactive GUI, installer, upgrade, and uninstall validation require a normal Windows desktop session
- release notes should be updated with final operator results when those checks are completed
- no legacy-import code was introduced in this release pass

## Known Limitations

- the application and installer are unsigned and may trigger SmartScreen
- search is project-local only
- search operates against structured report JSON loaded in memory
- legacy report importer is not implemented
- no saved searches or cross-project search
- no semantic or AI-assisted search
- finalized-report revision workflow is not implemented
- deletion requires report files not to be actively locked by external programs

## Rollback Procedure

Source rollback point:

```powershell
git checkout v0.3.0-alpha
```

Then rebuild with:

```powershell
pwsh ./scripts/publish-release.ps1
pwsh ./scripts/build-installer.ps1
```
