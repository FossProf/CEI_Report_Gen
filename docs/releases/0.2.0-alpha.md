# SPINgen 0.2.0-alpha

- Release tag: `v0.2.0-alpha`
- Release commit SHA: pending tag creation
- Build configuration: `Release`
- Target runtime: `win-x64`
- Installer filename: `SPINgen_0.2.0-alpha_x64.msi`
- Publish directory: `artifacts/publish/win-x64/`
- Release date: August 9, 2026

## Feature Summary

- SPINgen application identity and Cornerstone branding
- project creation, opening, and editable Project Settings
- application settings and recent-project support
- project dashboard, readiness panel, and reports grid
- blank-report creation and New Report from Selected
- report validation, preview generation, finalization, and overwrite protection
- Open XML generation with photo and signature support
- Windows self-contained publish and MSI installer build path

## Known Limitations

- The build is unsigned, so Windows SmartScreen may warn.
- Final reports remain immutable after finalization; revision workflow is not implemented yet.
- Report search and filter features are intentionally not present in this baseline.
- Manual GUI and installer smoke checks depend on access to an interactive Windows desktop session.

## Test Result Summary

- `dotnet clean CEI_Report_Gen.sln --configuration Release`
- `dotnet restore CEI_Report_Gen.sln`
- `dotnet build CEI_Report_Gen.sln --configuration Release`
- smoke/regression suite
- publish and MSI build
- runner script verification

## Rollback

Recover this baseline with:

```powershell
git checkout v0.2.0-alpha
```

Then rebuild using the normal release process:

```powershell
pwsh ./scripts/publish-release.ps1
pwsh ./scripts/build-installer.ps1
```
